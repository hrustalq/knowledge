Seven tabs. Everything here is an **override of a code default**: `null` means inherit the
`ASSISTANT_*` environment variable, so an empty configuration reproduces the pre-settings
behaviour exactly, and a release can still improve a shipped prompt for workspaces that
never touched it.

## Providers

Named profiles — base URL, model, credential, capabilities. `openai-compatible` covers
OpenAI, Ollama, LM Studio and vLLM; `deepseek` and `gen-api` only pre-fill a base URL and
model.

Which profile serves a call is first-hit-wins:

```
thread pin  →  agent pin  →  purpose route (chat / review / extraction)  →  inline config  →  env
```

A workspace with no profiles behaves exactly as it did before profiles existed. A disabled
or deleted profile falls through to the next source rather than failing the call.

Credentials are AES-256-GCM encrypted, write-only over the API (you see whether one is set
and its last four characters). Without `SETTINGS_ENCRYPTION_KEY` secret _writes_ are
disabled; an undecryptable row falls back to the environment credential.

## Agents

A named actor: instructions, tool allowlist, model, output contract. Ten are built in —
`router`, `researcher`, `author`, `reviewer`, `drafter`, `planner`, `extractor`,
`glossarist`, `transcriber`, `curator` — covering every model call site in the product. A
custom agent may not shadow a built-in name.

Two rules matter:

- **The tool allowlist intersects, never unions.** A settings row cannot widen what a
  model reaches.
- **The router is deterministic first.** Capability, budget and enablement are decided in
  code; the model only breaks ties between candidates that already passed. An LLM picking
  the model would itself be a call somebody had to pick a model for. Rejections are
  recorded with their reason.

`curator`, `reviewer` and `glossarist` can run in the background, on a schedule. A run
must have an owner: it rehydrates a real principal and passes the same access checks an
HTTP request would. Findings become changes through **Propose**, which runs the drafter
and opens a merge request attributed to _you_, not to the run's owner — merging is your
act.

## Skills

Instruction packs appended to the system prompt, matched by explicit selection or trigger
words. Capped at 3 per turn and 8k characters.

## Plugins

External MCP servers. Their tools are namespaced `mcp__<slug>__<tool>` so they can never
shadow a built-in, and their output is wrapped as **untrusted data**. Plugin URLs are
DNS-resolved and refused on private, loopback, link-local and carrier-grade NAT ranges
unless `AI_PLUGINS_ALLOW_PRIVATE_URLS` is set — an SSRF guard, since the server is the one
making the request.

## Budgets and usage

Budgets are checked before each call, not reserved, and are opt-in per workspace. Over
budget returns **429** with a specific error code rather than a generic failure.

Every upstream call writes one usage row — tokens, cost, operation, provider, user — which
serves both the usage charts and the call log. Prompt and completion text is _not_ stored
there; that lives with the conversation.
