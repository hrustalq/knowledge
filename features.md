# Список фич на рассмотрение

    - Просмотр документа (полный)
    - Виджет поиска с фильтрами
    - Редактор (как в confluence) с поддержкой ссылок, референсов, диаграмм, пдф, виджетов итд
    - Автоматический ре-индекс зависимых документов при обновлении (при мерже)
        - Обновление данных на фронте (инвалидация кеша, уведомления)
    - Просмотр ревизий документа
    - Просмотр графа документа (зависимости и связанные сущности)
    - Разделение на процессы, юз-кейсы, контракты, erd итд (категоризация)
    - Вложенность документов, как в confluence (с директориями)
    - ИИ помощник при создании / ревью документов, автогенерации, подсказки, проверка на ошибки, поиск релевантных файлов
    - Логи других пользователей (лента как в jira/confluence)
